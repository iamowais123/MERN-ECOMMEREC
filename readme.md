## 🧠 Project Overview

**BookKart** is a full-featured e-commerce application designed to simulate a real-world online bookstore experience.

It allows users to browse books, manage carts, securely pay online, and track orders — while admins get full control over inventory, users, and orders.

The platform follows modern architecture principles ensuring **performance, scalability, and maintainability**.

---

## ✨ Core Features

### 👤 User Side

* 🔐 Authentication system

  * OTP-based login
  * Google OAuth integration
* 📚 Browse books with category & advanced filters
* 🔎 Search & filter optimization
* ❤️ Wishlist management
* 🛒 Add to cart & Buy Now flow
* 💳 Secure checkout (Razorpay integration)
* 📦 Order tracking & history
* 👤 Profile management

---

### 🛠️ Admin Panel

* 📊 Dashboard overview
* 📦 Product management (CRUD operations)
* 👥 User management
* 📑 Order handling & tracking

* React.js + TypeScript

### 🖥️ Backend

* MongoDB

* OTP Verification
* Google OAuth

### 💳 Payment Integration

* Razorpay Payment Gateway

## 🏗️ Architecture Overview

```text
Client (React + Redux)
        ↓
REST API (Node + Express)
        ↓
Database (MongoDB)
        ↓
External Services:
   - Razorpay (Payments)
   - Google OAuth (Auth)
```

## ⚙️ Setup Instructions

### 🔹 Clone Repository

```bash
git clone https://github.com/your-username/bookkart.git
cd bookkart
```

### 🔹 Backend Setup

```bash
cd server
npm install
npm run dev
```

### 🔹 Frontend Setup

```bash
cd client
npm install
npm start
```

---

## 🔐 Environment Variables

Create `.env` in **server/**

```env
PORT=5000
MONGO_URI=your_mongodb_url
JWT_SECRET=your_secret_key
RAZORPAY_KEY=your_key
RAZORPAY_SECRET=your_secret
GOOGLE_CLIENT_ID=your_google_client_id
```
